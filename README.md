# Trovato AI

> Find tickets before everyone else.

Trovato AI is an AI-powered mobile application that helps travelers discover tickets for museums, attractions, festivals, exhibitions and events before they sell out.

The application understands natural language, searches multiple providers, suggests alternatives when tickets are unavailable, and allows users to create availability alerts.

---

## Vision

Planning a trip should be exciting—not stressful.

Trovato AI removes the frustration of discovering that an attraction is already sold out by proactively helping travelers find availability and suitable alternatives.

---

## MVP Features

- AI conversational search
- Museum & attraction discovery
- Ticket availability
- Alternative recommendations
- Availability alerts
- Saved favourites
- Trip planner
- Push notifications
